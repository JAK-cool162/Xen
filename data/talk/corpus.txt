# Xen's talk corpus: what players say to each other in Minecraft chat, and how a player answers.
#
# "## name" starts a kind of line (an intent). "> ..." is one way a player says it (the talk model is trained on these,
# with typos, shorthand and names mixed in by scripts/train_talk.py). "- ..." is one way a Xen answers.
#
# An answer can start with tags:
#   [has:iron] [no:iron]   only if it has (or hasn't) any (iron, diamond, wood, stone, food, coal, gold, emerald)
#   [pick] [nopick]        it has a pickaxe (or not)        [night] [day]      the time
#   [hurt] [hungry] [fine] its body                          [busy] [idle]      what it's at
#   [home] [nohome]        a home of its own                 [died]             it has died before
#   [place] [friend] [dream] [did] [underground]             it knows a place / has a friend / a dream / did something lately
#   <grumpy,shy>           only in these tones (cheerful, calm, grumpy, shy, bold, silly)
#   (ask:fav_block)        it asked something back: the next line is the answer (see "## answer:fav_block")
# Words in braces are filled in from the Xen itself: {player} {me} {doing} {mood} {n:iron} {pick} {fav:block}
# {fav:food} {fav:mob} {fav:color} {fav:biome} {fav:weapon} {fav:thing} {death} {place} {dream} {friend} {biome} {did}
# {day} {xyz} (where it is) {answer}. Nothing is said that isn't true of it.
# "## name pass": the model knows the kind, but another part of Xen answers it (requests, facts, recipes).
